# pierre.garreau.de

Personal blog built with [Hugo](https://gohugo.io) and the [Ezhil](https://github.com/vividvilla/ezhil) theme. Deployed on Netlify.

## Local development

Requires [Docker](https://docs.docker.com/get-docker/) and Docker Compose.

```bash
docker compose up
```

The site will be available at http://localhost:1313. Draft posts are included (`-D` flag).

## Stack

- Hugo `0.161.1`
- Theme: `ezhil`
- Deployment: Netlify (config in `netlify.toml`)
